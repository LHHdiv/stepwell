# 提示词 01 · 系列规划师（Series Architect）

> **用途**：你想学一个新知识领域时，用这个提示词让 AI 为你生成一整套课程的
> 大纲规划（输出 JSON，后续逐章写作时使用）。
>
> **用法**：复制下面全部内容发给大模型，把最后的 `{主题}` 换成你想学的知识，
> 可以补充你的背景和目标。

---

```text
你是一位顶级的学习课程设计师。我要系统学习一个新知识领域，请你为我设计一套完整的系列研读课程大纲。

# 我要学的主题
{主题}
（可选补充：我的背景是……；我的目标是……；我每天能投入约 XX 分钟）

# 你的任务
1. 把这个主题设计成一门「从零到能实践」的系列课，共 12～30 讲；
2. 每讲是一个独立的知识单元，但整个系列必须循序渐进、前后呼应；
3. 用「分卷（phases）」组织章节，每卷是一个学习阶段（例如：卷一·建立世界观）；
4. 输出必须严格符合下面的 JSON Schema。

# 输出格式（只输出 JSON，不要任何多余解释）
{
  "title": "系列名（中文，简洁有力）",
  "en": "ENGLISH NAME",
  "sub": "一句话概括这个系列",
  "intro": "2~3 句话的介绍：学完能得到什么",
  "category": "ai | source | math | engineering | life 五选一",
  "level": "intro | core | deep 三选一",
  "phases": [
    { "name": "卷一·阶段名", "chapters": ["第00讲标题", ...] }
  ],
  "chapters": [
    {
      "no": 0,
      "slug": "short-english-slug",
      "title": "第NN讲·标题",
      "summary": "这一讲讲什么、为什么重要（50字内）",
      "objectives": ["学完本讲你能……", "……"],
      "tags": ["标签1", "标签2"],
      "prerequisites": ["依赖的前置讲的编号"]
    }
  ]
}

# 设计原则
- 第一讲必须是「导读」：说明这个领域的地图、怎么学这门课、需要准备什么；
- 每卷开头的第一讲负责建立该阶段的「心智模型」，再进入细节；
- 理论与实践交替：每 3~5 讲安排一次「动手/练习/实验」性质的讲次；
- 难度曲线平滑：后面的讲允许引用前面的讲，不允许跳跃式引入概念；
- 中文标题格式固定为「第NN讲·标题」，NN 是两位数字（00、01……）。
```

---

## 产出后怎么用？

1. 把 AI 输出的 JSON 保存下来（比如存成 `大纲.json`）；
2. 在本地仓库执行 `npm run new:chapter -- <系列id>` 建好目录；
3. 打开 [提示词 02 · 章节写作者](#)，把大纲 JSON 和章节编号一起喂给它，逐章生成正文；
4. 全部生成后按《发布指南》（docs/publish-workflow.md）提交上线。
