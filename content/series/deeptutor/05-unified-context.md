老师走进教室，手上应该已经有：今天课题、学生昨天的笔记、要不要用实验室、用中文还是英文讲。不可能讲到一半再满学校找人设卡。DeepTutor 把这些收进一个叫 `UnifiedContext` 的资料包。英文可以记成「统一上下文」，人话就是**这一轮的书包**。定义在 `deeptutor/core/context.py`。

## 书包是这一轮的，不是走廊上的储物柜

每一轮对话 new 一个书包，随着函数一层层传下去。不要把它想成全局开关：两个人同时问问题，如果共用一个储物柜，讲义会串台。

里面比较重要的几袋：

| 袋子 | 人话 | 空了会怎样 |
|---|---|---|
| 学生的话 | 这一句提问 | 没新问题 |
| 近期聊天 | 这节课已经说过的 | 忘掉上一句公式 |
| 知识库名字 | 带了哪几本教材 | 检索按钮可能挂不上 |
| 记忆摘要 | 对你这个人已经知道的 | 每次都像新老师 |
| 人设 | 用什么口气讲 | 前半句官方腔、后半句突然幽默 |
| 技能目录 | 有哪些讲义大纲可翻 | 把整本技能塞进开场白会撑爆 |
| 附件 | 图片、PDF | 模型看不见你贴的图 |
| 语言 | 中文还是英文答 | 界面中文、讲解英文 |
| 小口袋 metadata | 本轮私货，比如「正在解题」 | 解题插件不知道该上场 |

人设那一袋的注释写得很坚决：必须从第一个字就起作用。家教不能先用默认嗓子说半句，再切换成你选的「严厉助教」。技能则只放**目录**，正文用到时再点「读某个技能」的按钮去拉。开场白永远可见的是索引，厚书按需打开——既省位置，也避免模型被无关技能带跑。

> 小结：人设是口音，要一开始就在；技能是参考书，列在书脊上即可。

## 两个特别容易搞反的开关

工具那一袋有个细微约定，注释写在字段旁：

- **没写（程序里常叫 `None`）**：意思是「我没指定，你按现场情况自动挂」。有教材就挂检索，有沙箱才挂运行代码。
- **写明空列表**：意思是「这次一个可选按钮都不要」。

伴侣机器人的主人还可能再加一道白名单：即使自动挂载想上网，主人说不准，就不给。两道闸是「课堂默认」乘「主人授权」。

如果你在代码里把「没写」和「空列表」当成一回事，所有自动挂载都会失效，模型又开始空口编讲义。这是本讲唯一需要你记住的编程细节，而且它跟是否精通 Python 无关——它是产品语义。

书包里还有 `allowed_builtin_tools`：产品聊天默认不限制；伴侣场景可能只允许一部分内置按钮。

> 小结：沉默表示「按规矩来」，空箱子表示「今天空手上课」。

## 试一试

打开 `deeptutor/core/context.py`，找到 `enabled_tools` 那一段英文注释，看它是否就是上面说的两种意思。再用自己的话给家人讲：「自动带教具」和「今天禁止所有教具」差在哪。
