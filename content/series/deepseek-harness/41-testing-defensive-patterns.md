终卷开篇。前面四十讲你反复见到一句话：dsh 要求源文件 100% 测试覆盖。这个数字听起来像营销口号，读完官方测试文档你会发现它是一套严密的质量工程的冰山一角。本讲拆冰山。

## 一、五层测试体系

| 层 | 命令 | 干什么 |
|---|---|---|
| 单元测试 | `pnpm test` | vitest 跑各包 tests/；优先边界、错误路径、事件顺序、并发竞态 |
| **覆盖率门禁** | `pnpm test:coverage` | 对 packages/*/*/src **按文件 100% 覆盖** |
| 真实 API e2e | `pnpm test:e2e` | 带密钥调真实模型与搜索 API |
| 快照 | `pnpm test:snapshot` | 无密钥固化对外行为（含 ACP 回放 + JSONL diff） |
| Web 浏览器快照 | `pnpm test:web` | Chromium 回放比对，CI 强制只读 replay |

几个细节见真章。单元层要求**每个注册表都有 HMR 安全测试**——对贡献内容的 fiber 执行 dispose 并断言清理完成：第 03 讲"注册可逆"不是口头承诺，是被测试逐个验证的契约。

覆盖率层的哲学最反直觉：

> 未覆盖的行往往是门禁正确标记出的**死代码（应删除），而非需要补写的测试。行覆盖率是必要条件，但永远不是充分条件：它证明行被执行过，不证明功能按交付预期工作。

大多数团队把 100% 当成要凑满的 KPI（于是出现大量无断言的垃圾测试）；dsh 把它当成**死代码探测器**——一行代码如果任何测试都走不到，凭什么存在？同一指标，两种文化，天壤之别。连豁免机制都设计过：pwsh 相关文件在没装 pwsh 的本机自动跳过并从门禁豁免，CI 上则全标准执行——绿色套件在任何主机上都有意义。

## 二、"推理在这里很便宜"

带密钥策略一节的标题就是态度：

> 我们是 DeepSeek，不要吝惜真实 API 测试。……只有带密钥运行才能证明 agent 能对接真实模型正常工作。

mock 测试的天花板在第 24 讲已经埋过伏笔（SSE 解析可以 mock，但真实服务器的怪癖 mock 不出来）。dsh 的做法：每个示例都提供无密钥和带密钥两版冒烟测试；密钥缺失时自动跳过让 CI 保持绿色——"**自动跳过不是成本信号**"。最有分量的论据是一份真实事故复盘：某次 ACP 默认导出丢掉了 inject，单元测试全绿、产品坏了——正是冒烟测试这类"外部世界检查"才能抓住的失败类别。

## 三、反作弊三原则

e2e 测试如何防止"智能体骗过测试"？文档给出三条铁律：

1. **验证外部世界，而非自我报告**："e2e 断言应重新运行命令或从外部重新读取文件；对 agent 自身输出做关键词探测会让作弊的 agent 通过。断言未修改的文件逐字节一致。"——智能体说"我删掉了那个文件"不算数，测试自己去 ls；
2. **优先真实实现**："只 mock 开销高或不确定的边界（LLM 适配器、网络、时钟）；下游一切保持真实。手写替身只能证明桥接层在搬运字节。"桥接工具测试甚至接入真实的 bash 工具跑真的 echo；
3. **测试真实入口路径**：测构建后的 lib/bin.js 由普通 node 执行——因为 tsx（TS 直跑工具）会掩盖结算竞态、模块解析失败这些只在产物里发作的问题。守卫的有效性也要证明："引入回归、观察变红、回退"——没有杀过人的守卫不算守卫。

这三条合起来是一种罕见的诚实：**测试的目标是证明产品在工作，而不是证明测试是绿的。**

## 四、防御性模式七条

docs/defensive-patterns.zh.md 是另一份浓缩智慧，七个小节全是并发与边界的血泪结晶：

1. **正交结果独立上报**——两个维度的结果别挤一个通道；
2. **公共约定两侧都要遵守**——协议的生产方和消费方同受约束；
3. **异步状态不是同步状态**——别把 Promise 的中间态当事实用；
4. **dispose 必须达到完全停稳，而不仅仅是请求停止**——第 25 讲重试插件的"等待活跃委托恢复完全停稳"正是此条的实践；
5. **在分发器中隔离回调异常**——监听者炸了不能带走派发器（第 13 讲 kick 的 catch 就是兜底现场）;
6. **绝不将环境变量或可预测路径暴露给不可信输出**；
7. **用 unlink 删除链接形态的路径**——符号链接的删除陷阱，安全细节控。

每一条都短小精悍，建议整篇通读——这是能直接迁移到你自己项目的经验包。

## 🔍 事故复盘 0001：全绿测试与崩掉的编辑器

docs/postmortem/0001 记录了一次真实事故：ACP 包的默认导出丢掉了 inject 字段——单元测试全绿，编辑器一连上就崩。正是这类“mock 测不出来”的失败催生了本章的“真实入口路径”纪律与带密钥冒烟测试。顺带一提，仓库共保留四篇这样的复盘（含 Landlock 沙箱误分类子进程失败、JS 表达式禁用文件系统工具等）——把失败写成文档，是这个仓库最动人的习惯之一；另外它还有一篇被否决的《NIH 审计》笔记，记录哪些“用现成库替换手写代码”的提议被驳回，因为那些手写形态正在承重。
