你一定用过 DeepSeek 的对话界面。输入问题，流式吐出答案——这背后是一个大模型在生成文字。

但如果我让你写一个程序：它不只回答问题，还能**读你的文件、执行命令、上网查资料、把任务拆成步骤自己完成**——你会发现光有模型根本不够。模型只负责"想"，谁负责让它"看"、"动"、"记"？谁负责在它想岔了的时候踩刹车？

负责这些的那一层软件，就叫 **Harness（马具）**。

## dsh 是什么

`dsh`（deepseek-harness）是 DeepSeek 在 2025 年开源的智能体运行框架。你可以把它理解为：

> **一套把"会说话的大模型"改造成"能干活的智能体"的完整骨架。**

同类产品你可能听说过：Claude Code（Anthropic 的编程智能体）、OpenAI Codex CLI、以及社区里的 pi 等。它们都是 harness——只是各家实现的哲学不同。dsh 的哲学写在它的文档里，只有一句话：

> **Everything is a plugin.（一切皆插件）**

模型适配器是插件、每个工具是插件、连主循环本身都可以被替换。没有写死在核心里的"特权部件"。这个设计让它在众多 harness 中特别适合**学习**和**改造**——而这正是你的目标。

## 为什么值得精读它

第一，它是官方出品且开源，代码质量高、测试覆盖率要求近乎苛刻（要求每个源文件 100% 覆盖），文档密度罕见地高——141 个子系统文档，中英双语。这意味着你在阅读时随时有"官方地图"可查。

第二，它足够完整。从会话日志到工具沙箱，从流式输出到上下文压缩，一个生产级智能体该有的器官它都有。读懂它，等于拿到了一张智能体解剖图——以后你看任何 Agent 框架，都是在看这张图的变体。

第三，也是对你最实际的一点：**它是 TypeScript 写的**。相比 C++ 或 Rust，TypeScript 的类型系统会把作者的意图直接写在代码里，读起来像读一份带注释的设计文档。

## 这个系列怎么学

本系列不是"API 使用教程"，而是**源码精读**。每一讲的固定结构是：

1. **心智模型**：先用类比和图景理解这一块"是什么、为什么存在"；
2. **对照源码**：打开真实文件，沿着关键类型定义和函数读下去；
3. **动手验证**：留一个小实验，让你亲手确认自己的理解；
4. **要点回顾**：三分钟复习本讲精华。

你不需要是专业开发者。遇到看不懂的语法，把它当成生词查就行——系列里遇到必要的 TypeScript 语法知识，我会就地解释。
