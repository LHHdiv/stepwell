## 这个包是什么

**与「编程」无关的 Agent 运行时。** 不管文件、不管 TUI、不管 `~/.pi`。它只保证：

1. 一份可变状态（系统提示、模型、消息、工具）
2. `prompt` / `continue` 启动循环
3. 循环里：把消息交给 `streamFn`、执行工具、发事件
4. steer / followUp 队列

coding-agent 是它的一个宿主。以后桌面学习伴侣也应是宿主：`new Agent({ streamFn, tools })`，不要 fork 一份循环。

同一包里还有第二套运行时：`src/harness/` 的 **可恢复会话规格**（`AgentHarness` + Session 三仓库 + drive 状态机）。现行 CLI 不用它。见下面「两条执行链」。

## 执行链走到这里时你在哪

```text
AgentSession.prompt
  → Agent.prompt
  → runAgentLoop → runLoop          【本包心脏】
       streamFn(...)                【coding-agent 注入的 pi-ai】
       executeToolCalls             【调用的是 Agent 状态里的 tools，实现来自 coding-agent】
```

## 两条执行链，不要混

本包里有两套「问模型、跑工具」的实现，宿主选其一，不要叠在一起。

```text
【现行 CLI / SDK 主链】
coding-agent AgentSession.prompt
  → Agent.prompt
  → runAgentLoop → runLoop
       streamFn(...)                 【packages/ai】
       executeToolCalls              【coding-agent 的 tools】

【可恢复会话规格 · harness】
coding-agent experimental session-worker / mini worker
  或 packages/server 挂 MemorySessionRepo
  → AgentHarness.create(session, models, tools, ...)
  → lane.accept(...)                 【只写盘，不开任务】
  → lane.drive({ operationId })      【按 pi.op.state.at 推进】
       models.streamSimple
       AgentHarnessTool.execute
```

**现行 `pi` 命令、交互 TUI、`-p`、RPC 主链都不进 harness。** 它们仍是 `new Agent` + `agent-loop`。coding-agent 只从本包拿 `Agent`、`AgentMessage`、`ThinkingLevel`、`setDefaultStreamFn`。

**何时会走到 harness：**

| 入口 | 路径 |
|---|---|
| 实验 session-worker | `packages/coding-agent/src/experimental/session-worker.ts` 的 `AgentHarness.create` |
| 实验 mini | `packages/coding-agent/src/experimental/mini/worker/run.ts` |
| 服务端会话仓库 | `packages/server` 用 `MemorySessionRepo` / `Session`，再由宿主挂 harness |
| 本包测试 | `packages/agent/test/harness/` |

harness 要解决的是 Agent 做不到的事：进程被杀后，从 `pi.op.state` 读出当前叶子、不重跑已结算的副作用、把对话树 / 分支 / 压缩 / 导航做成原子事务。规范正文在 `packages/agent/docs/harness.md`。本目录是对着源码走的课表，不是那份英文规格的翻译。

`src/search/index.ts` 只有类型骨架，规范里标为 S3 未实现。`watchSession` 仍抛 `SliceNotImplemented`。

## 和 coding-agent 的边界

| 问题 | 现行 CLI | harness |
|---|---|---|
| 四个默认工具 | coding-agent `core/tools/` | 本包 `harness/tools/` + `NodeExecutionEnv` |
| 系统提示中文/英文 | coding-agent `system-prompt.ts` | 宿主 `systemPrompt` 选项 + `formatSkillsForSystemPrompt` |
| JSONL 怎么写盘 | coding-agent `session-manager` + AgentSession subscribe | 本包 `JsonlSessionRepo` 事务行 |
| 模型 HTTP | packages/ai，经 `streamFn` | `models.streamSimple`，经 drive generation |
| 要不要再问一轮 | **本包** `runLoop` | **本包** `runCheckpoint` / inbox |
| 崩溃后工具 | 尽力靠已落盘的 JSONL | `pi.op.state` + replay never/safe |

读主链时把 `streamFn` 当「一个能 async iterate 事件的函数」。下一包再打开它。
