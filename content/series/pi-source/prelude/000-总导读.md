范围：仓库根目录 + `packages/` 下每一个子包。不是使用教程。

约定：

- **一个源码 `.ts` 一篇中文讲解。** 生成的 `providers/data/*.json` 合写在 [ai/providers/00-data-json目录.md](/series/pi-source/ai/061-data-json%E7%9B%AE%E5%BD%95/)，文内按文件分节。`*.lazy.ts` 并入对应非 lazy 实现那一篇，标题写清两个文件。agent harness 的 testing 夹具合写一篇，文内分节。
- 左边源码、右边文档。类型当旁注：[学前/01-如何读TypeScript.md](/series/pi-source/prelude/001-%E5%A6%82%E4%BD%95%E8%AF%BBTypeScript/)。
- 短工具函数的文章也短，因为源码本身就十几行；主链文件（main / sdk / agent-loop / compat）是长文。

## 执行主链（先读，才不会在 700 篇里迷路）

```text
root/16-pi-test.sh
  → coding-agent/01-experimental.cli.ts
  → 03-setup.ts → 04-main.ts
  → 07 Runtime → 08 Services → 09 sdk.createAgentSession
  → 10 print-mode 或 interactive-mode
  → 11 AgentSession.prompt
  → agent/01-agent.ts → 02-agent-loop.ts
  → ai/03-compat.ts 与 04-models.ts（streamSimple）
  → ai/api/*.ts（按 model.api）
  → coding-agent/core/tools（execute）
交互模式另加 tui/02-tui.ts
```

实验 `PI_EXPERIMENTAL=1 ./pi-test.sh server|client` 才走 chord + protocol + client + server。

## 从哪打开

1. 学前三篇。
2. [root/16-pi-test.sh.md](/series/pi-source/root/020-pi-test-sh/) → [coding-agent/01-experimental.cli.ts.md](/series/pi-source/coding-agent/467-experimental-cli-ts/) 一直读到 agent-loop。
3. [ai/00-模块导读.md](/series/pi-source/ai/060-%E6%A8%A1%E5%9D%97%E5%AF%BC%E8%AF%BB/) 的执行链，再打开 [03-compat.ts.md](/series/pi-source/ai/064-compat-ts/)、[04-models.ts.md](/series/pi-source/ai/065-models-ts/)、你正在用的那家 `ai/providers/<id>.ts.md`。
4. 其余包按导读标明的「走不走到」决定深读还是当地图。
