后面每篇都会出现这些词。这里用生活里的事解释一遍。读源码时遇到不懂的词，先回到这里。

你不需要先学会 TypeScript。你只需要能：打开一个文件、用搜索找到一个名字、知道「下面缩进的那几行是一组步骤」。

---

## 1. 源码是什么

源码是工程师写给电脑看的说明书。Pi 主要是 `.ts`（TypeScript）文本文件。

- **读源码** ≠ 写程序。像读菜谱：你能看懂「先洗菜再下锅」，不必自己开餐厅。
- 文件名 `agent-loop.ts` 只是一本说明书的书名。真正干活的是书里的 **函数**。

这个仓库是 **monorepo**（单一仓库里放多个互相依赖的包）。顶层 `packages/` 下每一个文件夹，发布到 npm 时可以是一个独立包。

## 2. 函数、调用、返回

| 词 | 人话 |
|---|---|
| **函数**（function） | 一份有名字的步骤清单。源码里常见 `function 名字(` 或 `export async function 名字(`。 |
| **调用** | 去执行那份清单。A 调用 B = A 做到一半说「先请 B 把这件事做了」。 |
| **返回** | 步骤做完，把结果交回给调用它的人。 |
| **参数** | 调用时附上的材料。像点餐单上的「少辣、外带」。 |
| **类**（class） | 一种模具。例如 `Agent` 模具；每 `new Agent(...)` 就是一个对象。 |
| **方法** | 属于某个类的函数。`prompt()` 是 Agent 这个模具上的一个按钮。 |
| **事件 / Event** | 过程中对外广播的进度：「开始了」「吐了一个字」「工具跑完了」。界面靠订阅事件来更新。 |
| **流 / Stream** | 不是做完一次性端上来，而是边做边往外送。 |

`async` / `await`：这件工作要等外面（网络、模型）回话，电脑先去干别的，回了再继续。第一遍把它想成「打电话等对方接」即可。

## 3. Pi 里反复出现的词

| 词 | 功能 | 人话 |
|---|---|---|
| **LLM / 模型** | 真正写句子、决定调不调工具的外部服务 | 厨房里的主厨，但不属于这家店 |
| **Provider** | 模型供应商（Anthropic、OpenAI、Google…） | 主厨来自哪家餐饮集团 |
| **Harness** | 给模型提供运行环境的软件 | 安全带 + 工具环：固定你、给你挂装备 |
| **Agent** | 模型 + Harness 一起工作时的整体 | 能自己读文件、跑命令、改代码的助手 |
| **系统提示 / system prompt** | 每次对话都带上的工作说明 | 入职第一天发的员工手册 |
| **Tool / 工具** | 模型可以「伸手去做」的一件小事 | 默认四件：读、写、改、跑命令 |
| **Agent 循环 / agent loop** | 问模型 → 可能调工具 → 把结果喂回去 → 再问，直到结束 | 主厨喊「我要刀」，后厨递刀，主厨继续做 |
| **Turn / 一轮** | 从一次用户输入（或一次工具结果）到模型这次回复结束 | 不是整个聊天，只是「这一趟」 |
| **Session / 会话** | 把很多轮串成一次可保存的聊天 | 一个聊天窗口，对应磁盘上的一份记录 |
| **Context / 上下文** | 这一轮真正送给模型看的那一段历史 | 桌上摊开的材料；不等于档案柜里的全部卷宗 |
| **Compaction / 压缩** | 历史太长时，用摘要替换一部分旧消息 | 把旧草稿收成纪要，腾出桌面 |
| **Prompt cache / 提示缓存** | 服务商对「开头一直没变的那截提示」打折复用 | 和压缩不是一回事 |
| **Skill** | 一篇给模型按需阅读的说明书（Markdown） | 一张流程卡，不是新程序 |
| **Extension** | 一段 TypeScript，能加工具、命令、钩子 | 给店里加一台新机器 |
| **Package** | 把 Skill / Extension / 主题等打包分享 | 别人做好的工具箱，可安装 |
| **SDK** | 用代码把 Pi 嵌进你自己的应用 | 桌面端未来会走这里，而不是改 TUI |
| **RPC** | 另一个进程用 JSON 行协议遥控 Pi | 两个程序隔墙喊话 |
| **TUI** | 终端里的界面 | 你现在看到的那个黑窗口 |

## 4. 怎么在编辑器里对着源码读

1. 打开文件夹 `/Users/lijunkai/Project/pi`。
2. 左侧找到文档说的路径，例如 `packages/agent/src/agent-loop.ts`。
3. `Cmd+F` 搜索函数名，例如 `agentLoop`。
4. 看到 `export function agentLoop` 或 `async function runLoop`，它下面缩进的就是这组步骤。
5. 看到另一行 `await executeToolCalls(...)`，那就是「请另一个函数接着干」。再搜索那个名字。

看不懂某一行语法可以跳过，抓住：**函数名叫什么、它请谁帮忙、结果送给谁。**
