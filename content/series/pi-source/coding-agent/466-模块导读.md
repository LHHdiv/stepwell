## 这个包是什么

面向用户的编程 Agent 产品。它把下面三块焊在一起：

- `pi-agent-core`：循环和状态
- `pi-ai`：给模型打电话
- `pi-tui`：终端界面

自己还负责：命令行、会话存盘、四个默认工具、Skill / Extension / 主题、系统提示、四种运行模式（交互、打印、RPC、SDK）。

## 源码目录

| 路径 | 干什么 |
|---|---|
| `src/cli.ts` | 发布入口（npm bin / 打包产物） |
| `src/experimental/cli.ts` | 本仓库 `./pi-test.sh` 入口 |
| `src/cli/` | 参数解析、登录子命令、第一次启动 UI |
| `src/main.ts` | 启动编排：从 argv 走到某一种 mode |
| `src/config.ts` | 包路径、`~/.pi/agent`、可 fork 的名字 |
| `src/index.ts` | SDK 对外导出，**不是** CLI 入口 |
| `src/core/` | 产品核心：会话、工具、设置、扩展、压缩、SDK |
| `src/modes/` | 交互 / 打印 / RPC |
| `src/extensions/` | 内置扩展（目前 llama.cpp） |
| `src/experimental/` 其余 | 实验中的多进程宿主 |
| `src/utils/` | 路径、图片、剪贴板等杂项 |
| `src/bun/` | Bun 打包与沙箱环境 |
| `docs/` | 上游英文使用文档，查命令用 |
| `examples/` | 扩展和 SDK 示例 |

## 怎么读（两条河）

**主链（01–11）**按进程调用顺序，读到 `AgentSession.prompt` 把消息交给 `packages/agent`。第一次跟路径只走这条。

**支线**按目录补全：CLI 其余文件、core 里装配/工具/压缩、modes 皮、内置扩展、bun。文件名里的数字在不同分组会重复，**点链接看全名**（`12-startup-ui.ts.md` 不是 `12-index.ts.md`）。

工具课（read/write/edit/bash/grep/find/ls/powershell）必须对照 [agent/02-agent-loop.ts.md](/series/pi-source/agent/243-agent-loop-ts/) 的 `executeToolCalls`：schema 校验 → beforeToolCall → `execute` 副作用 → 工具内截断 → toolResult。`stopReason === "length"` 时 loop **不调用** execute。
